Kompres foto & video

Pengaturan

Foto — ukuran maksimal (sisi terpanjang)
Foto — kualitas: 75%
Video — resolusi
Video — kualitas

Video dikompres sambil diputar (butuh waktu ±sama dengan durasi video). Jangan kunci layar / pindah app selama proses.

Hasil

"Simpan / Bagikan" membuka menu iPhone → pilih Simpan Gambar/Video (ke Foto) atau Simpan ke File. Setelah itu hapus versi lama di Foto supaya ruang benar-benar lega.

Cari sampah

Pilih banyak foto/video/file. App mencari duplikat persis, foto mirip, screenshot, dan file terbesar. Semua dianalisis di HP.

Brankas File

Privasi

  • File tidak pernah diupload. App dikunci (Content-Security-Policy) sehingga tidak bisa mengirim data ke server mana pun.
  • Brankas disimpan di penyimpanan app di iPhone ini saja.
  • Setelah terpasang, app jalan offline.

Pasang di iPhone

  • Buka di Safari → tombol Bagikan → Tambah ke Layar Utama.
  • Buka dari ikon di layar utama (bukan dari tab Safari) supaya Brankas tidak dihapus otomatis oleh iOS.

Batasan (aturan iPhone)

  • App web tidak bisa menghapus langsung dari app Foto. Bersihkan → tandai → hapus manual di Foto (atau kompres dulu, simpan, lalu hapus aslinya).
  • Kompres foto menghapus data lokasi/EXIF (lebih privat).
  • Kompres video berjalan real-time; video panjang butuh waktu lama.
